# BrewAssistant 2026.10.0b5 — RAPT Pill resolver / cockpit preview

- Version: `2026.10.0b5` / tag `v2026.10.0b5`
- Channel: prerelease via HACS. SOP: `dev → beta → main`.

## Scope
- Read-only atomic RAPT Pill BLE/Cloud Link selection (SG and temperature always from one source).
- BLE priority and two distinct BLE observations required to recover from Cloud Link.
- Cloud Link disconnect disqualifies candidate; HA `last_updated` is only an imperfect time proxy.
- Four normalized diagnostics sensors and a single Bluetooth/Wi-Fi Pill icon.
- Stale/unknown-pill-data warnings in Swedish fermentation cockpit.
- No integration of resolver into controllers, fermentation runtime or Brewfather stream.

## GF30 issue found before promotion
User attempted a 21.5 °C controller setpoint on 2026-10-08. Upstream `grainfather.set_controller_target_temperature` reported: `GF30 target 21.50 °C was not verified by fresh MQTT readback`.

This does not prove that controller rejected the write. Do not repeat the command without inspecting the actual GF30 target and upstream readback telemetry. Never bypass fresh readback or enable direct hardware writes to mask the failure. This issue is not caused by the read-only Pill resolver as far as code paths show.

## Release gates
Before tagging prerelease, require beta merge commit via **Create a merge commit**, green CI/Hassfest/HACS and isolated HA/RCL test on the exact beta merge SHA. Confirm fresh readback problem is identified or recorded as a separately blocked GF30 test. `main` remains unchanged.

## Tillägg 2026-10-09 — Brewday/RCL Assist
- Tre user-facing Brewday-lägen: Manual Brewing, Brewfather Brewing och RCL Brewing.
- RCL Brewing gör RAPT/BrewZilla till ensam recipe/step/timer/target-owner.
- BA Learning får endast heat-utilization + pump ON/OFF/utilization i RCL Assist; target och normal heater-switch blockeras.
- RCL Assist auto-applies inom denna smala scope först när BA read-only uttryckligen är av.
- RCL/BF source-loss går till Manual fallback med cached recipe context; reconnect återtar automatiskt source ownership.
- Den cachade externa timelinen/profilen importeras konservativt till befintlig ManualPlan så operatören kan fortsätta samma batch lokalt; extern cache ligger kvar oförändrad som reconnect-referens.
- Fallback/ManualPlan är runtime-lokal; persistens över full HA-restart är fortfarande separat acceptanspunkt.
- Global STOP/ABORT är fortsatt överordnad source och försöker STOP/OFF/0/main OFF.
- Ingen fysisk acceptans följer av denna kod; vattenprov krävs före promotion.
