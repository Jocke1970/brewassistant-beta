# BrewAssistant 2026-10 — GF30 Liquid Cooler readiness beta (v2026.10.0b3)

**Releasenamn:** `2026.10.0b3`  
**GitHub-tagg:** `v2026.10.0b3`  
**Integrationsmanifest:** `2026.10.0b3`  
**Releasekanal:** Pre-release / HACS

## Syfte

2026.10.0b3 kopplar BrewAssistants GF30-backend till den externa Liquid Cooler-kedjan
som en strikt **read-only** observationsyta.

BrewAssistant får bättre underlag för framtida cooling readiness utan att äga
eller aktivera någon kylhårdvara.

## Coolant / Liquid Cooler mappings

Befintliga valfria mappings:

```text
gf30_coolant_temp_entity
gf30_freezer_air_temp_entity
gf30_coolant_thermostat_entity
```

Nya valfria mappings:

```text
gf30_cooler_power_entity
gf30_cooler_switch_entity
```

Tomma mappings är fortsatt giltiga.

## Observerad telemetry

När mappings är satta kan BA observera:

- coolant/reservoir temperature
- freezer-air temperature
- freezer-air minus coolant delta
- thermostat state
- thermostat target temperature
- thermostat hvac_action / cooling demand
- Liquid Cooler power
- Liquid Cooler switch state

## Nya sensorer

```text
sensor.brewassistant_gf30_cooler_power
sensor.brewassistant_gf30_cooler_switch_state
```

## Readiness semantics

Den viktiga skillnaden i denna release är mellan **monitoring readiness** och
**validated cooling readiness**.

En färsk coolant-sensor kan ge:

```text
status: monitor_ready
monitoring_ready: true
```

men aktiv kylning förblir:

```text
cooling_readiness: not_validated
safe_setpoint_known: false
coolant_mixture_verified: false
```

Det förhindrar att BA tolkar frisk telemetry som bevis för att kylmediet eller
setpoint-gränserna är säkra.

## Power / switch boundary

Power och switch används endast som observerad telemetry.

BrewAssistant:

- infererar **inte** compressor running från watt;
- växlar **inte** cooler switch;
- ändrar **inte** thermostat target;
- startar eller stoppar **inte** GF30 cooling pump.

## Ownership

```text
Fermentation profile
  -> BrewAssistant GF30 target supervisor
  -> GF30 controller
       -> heater
       -> cooling demand / GF30 pump
             -> cooling loop
                  -> Liquid Cooler reservoir

Home Assistant climate/thermostat
  -> owns Liquid Cooler/freezer ON/OFF

BrewAssistant
  -> observes only
```

## Fälttest efter installation

Sätt de fem mappings som motsvarar den verkliga installationen och verifiera att
BA-snapshoten visar rätt temperaturer, thermostat state/target, cooler power och
switch state.

Ingen automatisk cooling-readiness ska godkännas i denna release.
